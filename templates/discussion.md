# {Feature Name} — Discussion

> Started: {DATE}
> Append-only. Written during the conversation, not after it.

What belongs here: **anything that would change how a reader interprets the decisions, but is not itself a decision.**

Decisions go to `decision_review.md`. What happened when goes to `session_log.md`. This file is for the reasoning that produced them and would otherwise exist only in a transcript.

Typical entries:

- **Grounding** — the existing practice, product or mental model this design maps onto, and why that mapping holds
- **Comparison** — the contrast that motivates a feature existing at all
- **Vocabulary** — the words the user uses to judge this, in their words
- **Framings dropped** — a way of seeing the problem that was considered and set aside, and what was wrong with it
- **Method** — how an open question is going to get answered, by whom

**Write before asking the next question.** The material that gets lost is the material generated between doc writes, so the write belongs to the insight rather than to a later tidying pass.
